безошибочность всех будущих ответов.

## Откат

Быстро вернуть модель Gemini: на Render установить DAY_SHOWCASE_PROVIDER=gemini
и дождаться применения настроек. Это возвращает прежний вызов Flash‑Lite,
но сохраняет уточнённый промпт. Значение по умолчанию — groq.

Полностью вернуть модель и старые промпты: git revert обоих коммитов внедрения
витрины (основного 7b2b270 и его корректировки), затем git push origin HEAD:main
и дождаться автоматического деплоя Render. Оба коммита отменяются от нового к старому.
Предыдущая рабочая версия: f40a4577b861260c240d11901b5c5d045ad9b208.
Сайт и его настройки технического перерыва для этого менять не требуется.
